# CFontalvo MP3 1.2.1 beta

## Corrección

- Cada lista ofrece ahora **Reproducir en orden** y **Reproducción aleatoria**.
- El modo elegido crea la cola completa de reproducción, por lo que los
  controles anterior y siguiente respetan el orden normal o mezclado.
- Al desplegar una lista, cualquier otra lista abierta se cierra
  automáticamente para mantener la pantalla compacta.
